Imagina que tienes el número de un día de la semana y quieres decir si es laborable. Con if te saldría una cadena larga: if day == 1 || day == 2 || …, luego un else if, luego otro… Funciona, pero cuesta leerlo. Cuando comparas un mismo valor con muchas opciones, hay una herramienta más clara: switch.

El concepto

switch evalúa un valor y lo compara con cada case, de arriba abajo: 

switch day {
case 1, 2, 3, 4:
	fmt.Println("laborable")
case 6, 7:
	fmt.Println("fin de semana")
default:
	fmt.Println("otro")
}
  • Se ejecuta solo el primer case que coincide. Después, el switch termina.
  • Un case puede tener varios valores separados por comas.
  • default se ejecuta si no coincide ninguno. Es opcional.

De arriba abajo

Animación: day vale 6. El switch lo compara con case 1, 2, 3, 4 y no coincide; después con case 6, 7, que sí coincide. Imprime «fin de semana» y termina: default ni se comprueba.

switch sin valor

También puedes escribir switch sin valor. Entonces cada case es una condición, y se ejecuta la primera que sea true. Es la forma limpia de escribir una cadena larga de if/else.

Un error a propósito

Repetir el mismo valor en dos case:

package main

import "fmt"
func main() {
	day := 6
	switch day {
	case 6, 7:
		fmt.Println("fin de semana")
	case 5, 6:
		fmt.Println("casi fin de semana")
	}
}
./prog.go:10:10: duplicate case 6 (constant of type int) in expression switch
	./prog.go:8:7: previous case

Cómo leer el error

./prog.go:10:10: duplicate case 6 (constant of type int) in expression switch
	./prog.go:8:7: previous case

El mensaje tiene dos líneas. La primera dice dónde está el problema (línea 10, columna 10): el valor 6 aparece por segunda vez. La segunda señala la primera aparición, en la línea 8. Si el 6 estuviera en los dos casos, solo se ejecutaría el primero, así que el segundo no serviría para nada. Go prefiere avisarte.

El error típico

Si vienes de C, Java o JavaScript, esperarás que, al terminar un case, la ejecución siga con el siguiente si no pones break. En Go no pasa: cada case termina solo y no hace falta escribir break. Si quieres que varios valores hagan lo mismo, no los pongas en casos seguidos: júntalos en un único case con comas.
