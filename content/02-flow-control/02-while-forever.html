A veces no sabes de antemano cuántas vueltas va a dar un bucle. Quieres doblar un número hasta que pase de 1000, o pedir datos hasta que lleguen bien. No hay un contador que vaya del 1 al 10: solo hay una condición que, tarde o temprano, dejará de cumplirse.

En otros lenguajes usarías un bucle while. En Go no existe esa palabra, porque no hace falta: el mismo for se encarga.

El concepto

Si quitas el inicio y el paso de un for, también puedes quitar los puntos y coma. Queda solo la condición: 

for n < 1000 {
	n *= 2
}

Se lee como «mientras n sea menor que 1000, dóblalo». Antes de cada vuelta, Go comprueba la condición; cuando es false, sale.

El bucle infinito

Si quitas también la condición, tienes un bucle infinito: 

for {
	// se repite para siempre
}

Parece peligroso, pero es muy útil cuando la decisión de parar está en medio del cuerpo. Para salir usas break, que termina el bucle en ese mismo momento y sigue con la línea de después.

El error típico

Escribir una condición que nunca cambia. Si olvidas la línea n *= 2, n vale 1 para siempre, la condición siempre es true y el programa no termina nunca. Lo mismo pasa con un for {} sin break.

Cómo darte cuenta

El compilador no puede avisarte: un bucle infinito es código válido. Lo notarás porque el programa se queda colgado y no muestra nada más. Para detenerlo, pulsa Ctrl+C en la terminal. Después revisa el bucle y pregúntate: ¿qué línea acerca la condición a false en cada vuelta?
