Hasta ahora tus programas hacían siempre lo mismo, línea tras línea. Pero casi todo programa real tiene que decidir: si el número es negativo, avisa; si la contraseña es correcta, entra; si no, muestra un error. Para eso está if.

El concepto

Igual que en for, la condición va sin paréntesis y las llaves son obligatorias: 

if n < 0 {
	fmt.Println("negativo")
} else if n == 0 {
	fmt.Println("cero")
} else {
	fmt.Println("positivo")
}

Go comprueba las condiciones de arriba abajo y ejecuta solo el primer bloque que se cumple. else if añade otra condición y else recoge todo lo demás. Los dos son opcionales.

La sentencia corta

El if también acepta una sentencia corta antes de la condición, separada por punto y coma: 

if p := price - discount; p > minimum {
	return p
}

La variable p solo existe dentro del if (y de sus else). Así no ensucias el resto de la función con variables que solo necesitas para decidir.

Un error a propósito

Poner el else en su propia línea, después de la llave:

package main

import "fmt"

func main() {
	age := 15
	if age >= 18 {
		fmt.Println("adulto")
	}
	else {
		fmt.Println("menor")
	}
}
./prog.go:10:2: syntax error: unexpected keyword else, expected }

Cómo leer el error

./prog.go:10:2: syntax error: unexpected keyword else, expected }

En la línea 10, el compilador encuentra un else que no esperaba. Go añade un punto y coma invisible al final de la línea 9, justo después de }, así que para él el if ya había terminado. La regla es sencilla: escribe siempre } else { en la misma línea.

El error típico

Usar la variable de la sentencia corta cuando el if ya ha terminado:

package main

import "fmt"

func main() {
	price := 20.0
	if p := price - 5; p > 10 {
		fmt.Println(p)
	}
	fmt.Println(p)
}
./prog.go:10:14: undefined: p

Cómo arreglarlo

./prog.go:10:14: undefined: p

undefined significa que en ese punto no existe nada con ese nombre. Si necesitas el valor después, declara la variable antes del if.
