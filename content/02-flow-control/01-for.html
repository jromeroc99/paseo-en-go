Imagina que quieres mostrar los números del 1 al 100. Podrías escribir cien líneas con fmt.Println, pero sería absurdo. Lo que necesitas es decirle al ordenador: «repite esto hasta que termines». Para eso existen los bucles.

Otros lenguajes tienen varios tipos de bucle: for, while, do… Go tiene uno solo: for. Es sencillo y sirve para todo.

El concepto

El for clásico tiene tres partes separadas por punto y coma:

for i := 0; i < 3; i++ {
	// cuerpo del bucle
}
  • Inicio (i := 0): se ejecuta una vez, antes de la primera vuelta.
  • Condición (i < 3): se comprueba antes de cada vuelta. Si es false, el bucle termina.
  • Paso (i++): se ejecuta al final de cada vuelta.

Dos detalles

Fíjate en dos detalles. No hay paréntesis alrededor de las tres partes, y las llaves { } son obligatorias, aunque el cuerpo tenga una sola línea. La variable i solo existe dentro del bucle.

El inicio y el paso son opcionales. Puedes dejarlos vacíos, pero los puntos y coma se quedan.

Un error a propósito

Si vienes de C o de Java, es fácil poner paréntesis por costumbre:

package main

import "fmt"

func main() {
	for (i := 0; i < 3; i++) {
		fmt.Println(i)
	}
}
./prog.go:6:9: syntax error: unexpected :=, expected )

Cómo leer el error

./prog.go:6:9: syntax error: unexpected :=, expected )

Lee el mensaje por partes: archivo prog.go, línea 6, columna 9. Es un syntax error (error de sintaxis): el código no tiene la forma que Go espera. Al ver el paréntesis, el compilador cree que empieza una expresión normal y no esperaba un := ahí. La solución es quitar los paréntesis.

El error típico

Equivocarte en una vuelta, por usar < donde querías <=, o al revés. for i := 1; i < 10; i++ va del 1 al 9, no al 10. Cuando escribas un bucle, comprueba siempre el primer valor y el último: ¿entra el extremo o no?
