Quieres duplicar cada número de una lista. Luego, elevar cada uno al cuadrado. Luego, quitarle el signo. Son tres bucles casi iguales; solo cambia la operación. Lo ideal sería escribir el bucle una vez y pasarle la operación como si fuera un dato más.

El concepto

En Go, una función es un valor, igual que un int o un string. Puedes guardarla en una variable, pasarla como argumento y devolverla como resultado. Su tipo describe su firma: 

func(float64, float64) float64

Se lee «una función que recibe dos float64 y devuelve un float64». Cualquier función con esa firma encaja, ya sea una que declaraste con nombre, una de la biblioteca estándar como math.Pow o una función anónima escrita en el momento: 

hypot := func(x, y float64) float64 {
	return math.Sqrt(x*x + y*y)
}

Un error a propósito

El tipo de una función incluye sus parámetros y sus resultados. Si la firma no coincide, no encaja: 

package main

import "fmt"

func apply(f func(int) int, x int) int {
	return f(x)
}
func shout(s string) string {
	return s + "!"
}

func main() {
	fmt.Println(apply(shout, 3))
}
./prog.go:14:20: cannot use shout (value of type func(s string) string) as func(int) int value in argument to apply

Cómo leer el error

./prog.go:14:20: cannot use shout (value of type func(s string) string) as func(int) int value in argument to apply

En la línea 14, el compilador compara los dos tipos: shout es func(s string) string, pero apply espera func(int) int. Recibe y devuelve tipos distintos, así que no sirve.

El error típico

Confundir llamar a una función con pasarla. hypot es la función; hypot(5, 12) es su resultado, un float64. Si escribes compute(math.Pow()), Go intenta llamar a math.Pow sin argumentos y protesta con not enough arguments in call to math.Pow. Para pasar la función, quita los paréntesis: compute(math.Pow).
