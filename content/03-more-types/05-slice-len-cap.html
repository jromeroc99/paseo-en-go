Ya sabes que un slice es una ventana sobre un array. Pero una ventana tiene dos medidas: lo que ves ahora y hasta dónde podría abrirse. Para usar bien los slices necesitas conocer las dos.

El concepto

Un slice tiene una longitud y una capacidad:

  • len(s) es la longitud: cuántos elementos contiene.
  • cap(s) es la capacidad: cuántos elementos hay en el array de debajo, contando desde el primer elemento del slice.

Volver a cortar

Puedes volver a cortar un slice para hacerlo más largo, siempre que no pases de su capacidad. Por eso s[:0] deja la longitud a 0 sin perder el array, y s[:4] la recupera. Si cortas por delante, con s[2:], la capacidad baja, porque la ventana ya empieza más adelante.

Longitud y capacidad

Animación: s es una ventana sobre un array de 6 elementos, con longitud 6 y capacidad 6. s[:0] cierra la ventana (longitud 0) pero el array sigue ahí, con capacidad 6. s[:4] la vuelve a abrir hasta 4. s[2:] mueve el inicio dos casillas sin mover el final: longitud 2 y capacidad 4.

El valor cero

El valor cero de un slice es nil: longitud 0, capacidad 0 y ningún array debajo. Para crear un slice de un tamaño concreto usas make([]T, len, cap). El tercer argumento es opcional; si lo omites, la capacidad es igual a la longitud.

Un error a propósito

La capacidad es el límite. Si intentas ir más allá, el programa se detiene: 

package main

import "fmt"

func main() {
	s := make([]int, 2, 4)
	s = s[:6]
	fmt.Println(s)
}
panic: runtime error: slice bounds out of range [:6] with capacity 4

Cómo leer el error

panic: runtime error: slice bounds out of range [:6] with capacity 4

Léelo por partes: los límites del corte están fuera de rango; pediste [:6] y la capacidad es 4. Para tener más sitio hace falta un array nuevo, y eso lo verás en la próxima lección.

El error típico

Tratar un slice nil como si fuera un error. No lo es: tiene longitud 0, puedes recorrerlo y, como verás con append, puedes añadirle elementos. Para saber si un slice está vacío, pregunta por len(s) == 0, que funciona igual con un slice nil y con uno vacío.
