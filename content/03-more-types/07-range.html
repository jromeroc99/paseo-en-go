Tienes un slice y quieres hacer algo con cada elemento: imprimirlo, sumarlo o comprobar si cumple una condición. Con un for clásico necesitas un contador, una condición con len y un incremento. Funciona, pero es mucho ruido para algo tan común.

El concepto

La forma range del bucle for recorre un slice elemento a elemento. En cada vuelta te da dos valores: el índice y una copia del elemento. 

for i, v := range s {
	// i es el índice, v es una copia de s[i]
}

Si solo necesitas uno de los dos, tienes dos opciones:

  • Solo el índice: for i := range s.
  • Solo el valor: for _, v := range s. El guion bajo, _, es el identificador vacío: le dice a Go que descarte ese valor.

Una nota moderna: desde Go 1.22 también puedes recorrer un número. for i := range 10 da vueltas con i de 0 a 9.

Un error a propósito

Go no permite variables declaradas que no se usan, y eso incluye las de un range: 

package main

import "fmt"

func main() {
	names := []string{"Ana", "Luis"}
	for i, name := range names {
		fmt.Println(name)
	}
}
./prog.go:7:6: declared and not used: i

En la línea 7, columna 6, está i: la declaraste y nunca la usas. Si no necesitas el índice, cámbialo por _: for _, name := range names.

El error típico

Cambiar v esperando cambiar el slice. v es una copia, así que esto no hace nada útil: 

scores := []int{1, 2, 3}
for _, v := range scores {
	v = v * 10
}
fmt.Println(scores) // [1 2 3]

Para modificar los elementos, usa el índice y escribe en el slice: scores[i] = scores[i] * 10. Así el resultado sí es [10 20 30].
