Quieres una función que lleve la cuenta: cada vez que la llamas con un número, te devuelve la suma acumulada hasta ahora. Esa suma tiene que vivir en algún sitio entre una llamada y la siguiente, pero no quieres una variable global que cualquiera pueda tocar.

El concepto

Un closure (clausura) es una función que usa variables declaradas fuera de ella, en el sitio donde se creó. La función recuerda esas variables y puede leerlas y cambiarlas aunque el código que las declaró ya haya terminado. 

func adder() func(int) int {
	sum := 0
	return func(x int) int {
		sum += x
		return sum
	}
}

adder devuelve una función. Esa función usa sum, que pertenece a adder. Cuando adder termina, sum no desaparece: sigue viva dentro del closure.

Lo más importante: cada llamada a adder crea una variable sum nueva. Dos closures creados por dos llamadas distintas no comparten nada.

pos va sumando 0, 1, 2, 3 y 4. neg va sumando 0, -2, -4, -6 y -8. Cada uno lleva su propia cuenta.

El error típico

Creer que dos closures comparten su estado porque salen de la misma función. En el ejemplo, pos y neg vienen de adder, pero cada uno tiene su sum. Si quisieras que dos partes de tu programa usaran la misma cuenta, tendrías que compartir el mismo closure, no llamar a adder dos veces.
