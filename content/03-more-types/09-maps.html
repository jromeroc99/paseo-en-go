Quieres guardar la edad de cada persona por su nombre, o el número de unidades de cada producto. Con un slice tendrías que recorrerlo entero cada vez para encontrar a «Ana». Necesitas buscar directamente por el nombre.

El concepto

Un map (mapa) asocia claves con valores. Su tipo es map[K]V: map[string]int asocia textos con enteros. Lo creas con make o con un literal: 

ages := make(map[string]int)
stock := map[string]int{"manzanas": 3, "peras": 5}

Las operaciones básicas:

  • Insertar o actualizar: m[key] = value.
  • Leer: v := m[key]. Si la clave no está, obtienes el valor cero del tipo.
  • Borrar: delete(m, key).
  • Preguntar si está: v, ok := m[key]. ok es true si la clave existe.

El valor cero de un map es nil. Un map nil no tiene claves, y no puedes añadirle ninguna.

Dónde vive cada clave

Animación: para guardar una clave, Go calcula su hash, un número que sale de la clave, y ese número elige un bucket. "Ana" cae en el bucket 2 y "Luis" en el 0. Al leer ages["Ana"], Go calcula el mismo hash y va directo al bucket 2.

Un error a propósito

Escribir en un map que nunca creaste:

package main

func main() {
	var ages map[string]int
	ages["Ana"] = 30
}
panic: assignment to entry in nil map

Cómo arreglarlo

panic: assignment to entry in nil map

El mensaje es directo: has asignado una entrada en un map nil. var solo declara la variable; para poder escribir, crea el map con make(map[string]int) o con un literal.

El error típico

Leer una clave que no existe y no darte cuenta. En el ejemplo, stock["manzanas"] devuelve 0 después de borrarla, igual que si hubiera 0 manzanas. Cuando necesites distinguir los dos casos, pregunta con ok.
