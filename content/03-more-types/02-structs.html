Un jugador tiene un nombre y una puntuación. Un punto tiene una coordenada X y otra Y. Podrías guardarlos en variables sueltas, pero entonces nada te dice que van juntas. Necesitas una forma de agruparlas bajo un solo nombre.

El concepto

Un struct (estructura) es un tipo que agrupa varios campos, cada uno con su nombre y su tipo: 

type Vertex struct {
	X int
	Y int
}

Accedes a cada campo con un punto: v.X. Si tienes un puntero p a un Vertex, también escribes p.X. Go sigue el puntero por ti, así que no hace falta escribir (*p).X.

Los literales

Para crear un valor usas un struct literal (literal de estructura): Vertex{1, 2} da valor a todos los campos en orden, y Vertex{X: 1} nombra solo los que quieres; el resto toma su valor cero. Con &Vertex{1, 2} obtienes directamente un puntero al nuevo valor.

Un error a propósito

El compilador conoce todos los campos de un struct. Si pides uno que no existe, te lo dice: 

package main

import "fmt"

type Player struct {
	Name  string
	Score int
}
func main() {
	p := Player{Name: "Ana"}
	fmt.Println(p.Points)
}
./prog.go:12:16: p.Points undefined (type Player has no field or method Points)

Cómo leer el error

./prog.go:12:16: p.Points undefined (type Player has no field or method Points)

En la línea 12, p.Points no está definido: el tipo Player no tiene ningún campo llamado Points. Suele ser una errata o un nombre que recordabas mal; revisa la declaración del struct.

El error típico

Pasar un struct por valor y esperar que la función lo cambie. Lo has visto en el ejemplo: moveCopy recibe una copia, así que v sigue siendo {10 2}. Si la función debe modificar el struct, recibe un puntero, como move, y la llamas con &v.
