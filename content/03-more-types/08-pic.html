Un tablero de tres en raya tiene filas y columnas. Una imagen es una cuadrícula de píxeles. Un slice te da una fila de valores, pero aquí necesitas dos dimensiones.

El concepto

Un slice puede contener cualquier tipo, incluidos otros slices. Un [][]string es un slice de filas, y cada fila es un []string. Accedes a una celda con dos índices: board[y][x] es la fila y, columna x.

Crear cada fila

La clave está en cómo se crea. make([][]string, 3) crea el slice de fuera con tres filas, pero cada fila es un slice nil: todavía no tiene celdas. Tienes que crear cada fila por separado, normalmente con un bucle: 

for y := range board {
	board[y] = make([]string, 3)
}

Como cada fila es su propio slice con su propio array, cambiar una celda de una fila no afecta a las demás.

El error típico

Crear el slice de fuera y olvidarte de las filas: 

package main

func main() {
	board := make([][]string, 3)
	board[0][0] = "X"
}
panic: runtime error: index out of range [0] with length 0

Cómo leer el error

panic: runtime error: index out of range [0] with length 0

board[0] existe, pero es una fila nil de longitud 0, así que no tiene índice 0. El mensaje lo dice con exactitud: índice 0 fuera de rango con longitud 0. Cuando veas «with length 0» en un slice de slices, comprueba que creaste cada fila.
