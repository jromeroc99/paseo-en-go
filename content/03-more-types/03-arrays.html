Los días de la semana son siete. Las casillas de un tablero de tres en raya son nueve. Cuando sabes de antemano cuántos elementos vas a guardar, y ese número no cambia nunca, puedes usar un tipo que lo diga.

El concepto

Un array (vector de tamaño fijo) guarda un número fijo de valores del mismo tipo. [3]int es un array de tres enteros. Accedes a cada elemento por su índice, que empieza en 0: a[0], a[1] y a[2].

Hay dos detalles importantes:

  • La longitud forma parte del tipo. [3]int y [5]int son tipos distintos, y un array no puede crecer ni encoger.
  • Un array es un valor. Al asignarlo a otra variable, o al pasarlo a una función, Go copia todos sus elementos.

Un error a propósito

Como la longitud se conoce al compilar, Go comprueba los índices constantes antes de ejecutar nada: 

package main

import "fmt"

func main() {
	var a [3]int
	a[3] = 7
	fmt.Println(a)
}
./prog.go:7:4: invalid argument: index 3 out of bounds [0:3]

Cómo leer el error

./prog.go:7:4: invalid argument: index 3 out of bounds [0:3]

En la línea 7, el índice 3 está fuera de los límites. La notación [0:3] significa «desde 0 hasta 3, sin incluir el 3»: los índices válidos son 0, 1 y 2. Un array de longitud n acaba en el índice n-1.

El error típico

Pensar que un [3]int y un [5]int son intercambiables porque los dos guardan enteros: 

var small [3]int
var big [5]int = small
cannot use small (variable of type [3]int) as [5]int value in variable declaration

Para Go son tipos tan distintos como int y string. Esta rigidez hace que los arrays se usen poco directamente. En la próxima lección verás los slices, que se apoyan en un array y sí pueden cambiar de tamaño.
