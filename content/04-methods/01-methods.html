Tienes un tipo Vertex con dos campos, X e Y, y quieres saber a qué distancia está del origen. Puedes escribir una función que reciba el vértice. Pero esa operación pertenece al tipo, y te gustaría escribirla así: v.Abs().

El concepto

Un método (una función asociada a un tipo) es una función con un argumento especial, el receiver (receptor), que va entre func y el nombre: 

func (v Vertex) Abs() float64

Dentro del método, v es el valor sobre el que lo llamas. Y no hay magia: un método es solo una función. v.Abs() hace lo mismo que AbsFunc(v); cambia la forma de llamarlo, no lo que hace.

Los métodos no son solo para los struct. Puedes declararlos sobre cualquier tipo que definas en tu paquete, por ejemplo type MyFloat float64. La única condición es que el tipo del receptor esté declarado en el mismo paquete que el método.

Un error a propósito

Intenta añadir un método directamente a int:

package main

import "fmt"

func (n int) Double() int {
	return n * 2
}

func main() {
	fmt.Println(3)
}
./prog.go:5:9: cannot define new methods on non-local type int

La línea 5, columna 9, es donde está int, el tipo del receptor. Non-local significa «que no es de tu paquete»: int es del lenguaje, así que no puedes tocarlo. La solución es definir tu propio tipo, type MyInt int, y declarar el método sobre él.

El error típico

Buscar clases. Go no tiene class, ni herencia, ni this. Tiene tipos, y los tipos tienen métodos. El receptor se llama como tú quieras; lo habitual es una o dos letras del tipo: v para Vertex, f para MyFloat.
