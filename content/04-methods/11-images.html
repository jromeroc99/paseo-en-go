Una imagen es una cuadrícula de píxeles de colores. El paquete image no te obliga a guardarla de una forma concreta: te pide que sepas responder a tres preguntas. Y eso, en Go, es una interfaz.

El concepto

image.Image tiene tres métodos: 

type Image interface {
	ColorModel() color.Model
	Bounds() Rectangle
	At(x, y int) color.Color
}

ColorModel dice cómo se representan los colores, por ejemplo color.RGBAModel: rojo, verde, azul y opacidad. Bounds devuelve el rectángulo que ocupa la imagen; image.Rect(0, 0, 100, 100) es un cuadrado de 100 por 100 que empieza en la esquina (0, 0). At devuelve el color del píxel en la posición (x, y).

Cualquier tipo puede ser una imagen

Cualquier tipo con esos tres métodos es una imagen, y funciona con todo lo que acepta image.Image, como png.Encode, que la guarda en formato PNG. Si solo necesitas una imagen en la que pintar, image.NewRGBA te da una ya hecha.

Un error a propósito

Un tipo al que le falta uno de los tres métodos:

package main

import (
	"image"
	"image/color"
)

type Square struct{}

func (s Square) ColorModel() color.Model {
	return color.RGBAModel
}
func (s Square) Bounds() image.Rectangle {
	return image.Rect(0, 0, 8, 8)
}

func main() {
	var img image.Image = Square{}
	_ = img
}
./prog.go:19:24: cannot use Square{} (value of struct type Square) as image.Image value in variable declaration: Square does not implement image.Image (missing method At)

Cómo leer el error

./prog.go:19:24: cannot use Square{} (value of struct type Square) as image.Image value in variable declaration: Square does not implement image.Image (missing method At)

Igual que en la lección de interfaces: la segunda parte del mensaje dice qué falta, missing method At. Añade el método y Square será una imagen.

El error típico

Olvidar que un uint8 solo llega hasta 255. Si conviertes una variable que vale 300, uint8(x) no da error: da 44, porque vuelve a empezar desde 0. Mantén los valores de color entre 0 y 255.
