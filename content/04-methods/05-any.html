fmt.Println acepta un número, un texto, un struct… lo que le des. ¿Cómo se declara un parámetro así, que acepte valores de cualquier tipo? Y una vez dentro, ¿cómo recuperas el valor con su tipo?

El concepto

Una interfaz pide una lista de métodos. Si la lista está vacía, interface{}, cualquier tipo la cumple, porque todos tienen al menos cero métodos. Es la empty interface (interfaz vacía). Desde Go 1.18 tiene un nombre más corto: any. Los dos son exactamente lo mismo.

Sacar el valor concreto

Para sacar el valor concreto usas una type assertion (aserción de tipo): t := i.(T) afirma que i guarda un T y te lo da. Si te equivocas, el programa se detiene con un panic.

Si no estás seguro, pide también un segundo resultado: t, ok := i.(T). Si i guarda un T, ok es true; si no, ok es false, t es el valor cero de T y no hay panic.

Un error a propósito

Afirma que la interfaz guarda un int cuando guarda un string:

package main

import "fmt"

func main() {
	var i any = "hola"
	n := i.(int)
	fmt.Println(n)
}
panic: interface conversion: interface {} is string, not int

Cómo leer el error

panic: interface conversion: interface {} is string, not int

Se lee tal cual: la interfaz guarda un string, no un int. Fíjate en que el mensaje escribe interface {} aunque en el código pusiste any: es el mismo tipo con otro nombre.

El error típico

Usar la forma sin ok cuando el valor viene de fuera y no sabes qué tipo tiene. Esa forma es para cuando estás seguro; si te equivocas, el programa entero se detiene. Ante la duda, escribe v, ok := i.(T) y comprueba ok.
