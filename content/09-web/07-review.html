Has terminado el módulo. Antes de seguir, repasa lo que ya sabes:

  • TCP: dos programas que hablan: una dirección y un puerto; Listen, Accept y Dial abren una conexión.
  • Tu propio socket: TCP es un flujo de bytes; un protocolo de líneas marca dónde acaba cada mensaje.
  • HTTP: texto sobre TCP: una línea de inicio, cabeceras, una línea en blanco y el cuerpo.
  • Un servidor con net/http: un handler por patrón; el código de estado va antes del cuerpo.
  • Una pequeña API JSON: encoding/json solo ve los campos exportados.
  • Plantillas con html/template: huecos que se rellenan con datos y se escapan solos.

Tu turno

Vas a escribir una pequeña web de notas, con una API para los programas y una página para las personas. Las dos muestran las mismas notas.

  • GET /api/notes responde las notas en JSON; [] si no hay ninguna.
  • POST /api/notes crea una nota con {"text": "..."} y responde 201; un JSON roto o un texto vacío dan 400.
  • GET / responde una página HTML con un <li> por nota, o <p>Todavía no hay notas.</p> si no hay ninguna.

Lo que escribes

Escribe todo en notes.go. Usa html/template para la página y un sync.Mutex para las notas. El patrón "GET /{$}" solo acepta la ruta /. 

type Note struct {
