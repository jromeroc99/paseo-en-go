Una API responde JSON, pero el navegador muestra HTML. Podrías montar la página a trozos con fmt.Fprintf, pero el HTML se mezcla con el código y cuesta leerlo. Y si un usuario escribe <b>sal</b>, ¿se ve como texto o se convierte en HTML de tu página?

El concepto

Una plantilla es el HTML de la página con huecos. {{"{{"}}.Title}} se rellena con el campo Title de los datos que le pasas. {{"{{"}}range .Items}} repite lo que hay hasta {{"{{"}}end}} una vez por elemento, y dentro, {{"{{"}}.}} es el elemento actual.

El paquete html/template además escapa cada valor: cambia < por &lt;, así que lo que escribe un usuario se ve como texto y nunca se convierte en HTML.

Datos y plantilla

Animación: a la izquierda, los datos, con el título Compra y dos elementos, pan y <b>sal</b>. Paso a paso se rellena la página: el título en el <h1>, un <li> por elemento, y el segundo sale escapado, como &lt;b&gt;sal&lt;/b&gt;.

El ejemplo

La plantilla es una constante con el HTML y sus huecos:

{{codeLines "examples/shoplist/main.go" 1 12}}

Parse lee la plantilla y Execute la rellena con los datos y escribe el resultado en os.Stdout:

{{codeLines "examples/shoplist/main.go" 14 23}}

Ejecuta el programa:

$ go run .
<h1>Compra</h1>
<ul>
  <li>pan</li>
  <li>&lt;b&gt;sal&lt;/b&gt;</li>
</ul>

Fíjate en el segundo elemento: el navegador mostrará <b>sal</b> tal cual, como texto, y no una palabra en negrita.

Un error a propósito

Olvidar el {{"{{"}}end}} del range:

const page = `<h1>{{"{{"}}.Title}}</h1>
<ul>
{{"{{"}}range .Items}}  <li>{{"{{"}}.}}</li>
</ul>
`
$ go run .
panic: template: page:5: unexpected EOF

goroutine 1 [running]:

Cómo leer el error

panic: template: page:5: unexpected EOF

El error es de la plantilla llamada page, en su línea 5, la última. EOF es el final del texto: la plantilla se ha acabado cuando aún esperaba el {{"{{"}}end}} del range. Es un panic porque template.Must para el programa si Parse falla. Después viene la pila de llamadas, que aquí puedes ignorar.

El error típico

Importar text/template en vez de html/template. Se usan igual, pero text/template no escapa nada: 

$ go run .
<h1>Compra</h1>
<ul>
  <li>pan</li>
  <li><b>sal</b></li>
</ul>

Ahora sal sale en negrita. Si un usuario escribe un <script>, se ejecutará en el navegador de quien abra la página. Para HTML, usa siempre html/template.
