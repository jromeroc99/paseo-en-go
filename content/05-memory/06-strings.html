Escribe len("año") y Go te dirá 4. Pero «año» tiene tres letras. No es un fallo: len no cuenta letras. Para saber qué cuenta, hay que ver cómo se guarda un texto en memoria.

El concepto

Un string es una fila de bytes que no se puede cambiar. El texto se guarda en UTF-8: cada carácter ocupa de 1 a 4 bytes. Las letras inglesas ocupan 1, la «ñ» ocupa 2 y el «€» ocupa 3.

  • Un byte es un número de 0 a 255: un trozo del texto.
  • Una rune es un carácter entero, como «ñ». Su tipo es rune.

En la memoria

Animación: «año» son cuatro bytes, 61 c3 b1 6f; la ñ ocupa dos, c3 y b1. len cuenta los cuatro. range lee una rune cada vez: la a en el byte 0, la ñ en los bytes 1 y 2, y la o en el byte 3.

Fíjate en el índice: salta del 1 al 3. Con un string, range te da la posición en bytes donde empieza cada rune, no el número de letra.

Un error a propósito

Un string no se puede cambiar. Intenta poner la primera letra en mayúscula: 

package main

import "fmt"

func main() {
	s := "hola"
	s[0] = 'H'
	fmt.Println(s)
}
./prog.go:7:2: cannot assign to s[0] (neither addressable nor a map index expression)

Cómo leer el error

./prog.go:7:2: cannot assign to s[0] (neither addressable nor a map index expression)

«No puedo asignar a s[0]». Entre paréntesis te da el motivo: no es una posición de memoria que puedas cambiar. Para cambiar un texto, crea uno nuevo: convierte el string en []rune, cambia lo que quieras y conviértelo de nuevo con string(r).

El error típico

Leer una letra con un índice. s[i] te da un byte, no un carácter: 

s := "año"
fmt.Println(s[1]) // 195: el primer byte de la ñ

Para recorrer caracteres usa range. Para contarlos o acceder a ellos por posición, conviértelo en []rune(s).

Tu turno

Escribe en runes.go dos funciones. CountRunes cuenta los caracteres, no los bytes. Reverse les da la vuelta: Reverse("año") es "oña". Si das la vuelta a los bytes, romperás la ñ.

func Reverse(s string) string
