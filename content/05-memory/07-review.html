Has terminado el módulo. Antes de seguir, repasa lo que ya sabes:

  • Bytes y direcciones: cada tipo ocupa unos bytes; un número que no cabe da la vuelta.
  • El stack: cada llamada apila un frame y lo quita al volver.
  • El heap: lo que escapa de su función vive en el heap; -gcflags='-m' te lo cuenta.
  • El recolector de basura: marca lo que alcanzan tus variables y libera el resto.
  • Alineación y padding: cada campo empieza en un múltiplo de su tamaño.
  • Strings, bytes y runes: len cuenta bytes; range lee runes.

Tu turno

Vas a escribir tu propio reparto de memoria: una arena. Es un bloque de bytes que reparte trozos uno detrás de otro, cada uno alineado, y que se libera entero de una vez. Algunos programas muy rápidos reservan así la memoria.

  • New crea una arena de size bytes.
  • Alloc reserva n bytes en el primer múltiplo de align libre. Si no caben, devuelve 0, false.
  • Reset lo libera todo.

Lo que escribes

Escribe todo en arena.go. Los campos de Arena los decides tú; los tests solo usan los métodos. 

type Arena struct {
	// tus campos
}

func New(size int) *Arena
func (a *Arena) Alloc(n, align int) (offset int, ok bool)
func (a *Arena) Reset()
