Este curso es un paseo por Go pensado para quien empieza a programar en este lenguaje. Cada lección explica un concepto, muestra un ejemplo y, cuando corresponde, propone un ejercicio que resuelves en tu propio ordenador.

Cómo funciona

  1. Lee la lección en esta web.
  2. Abre la carpeta del ejercicio en tu editor y escribe tú todo el código que te pide.
  3. Ejecuta go test. Cuando todos los tests pasan, el ejercicio está resuelto.
  4. Marca la lección como completada. Tu progreso se guarda en este navegador.

Instalar Go

Descarga Go desde go.dev/dl y comprueba la instalación en una terminal: 

go version

Descargar los ejercicios

git clone https://github.com/OWNER/paseo-en-go.git
cd paseo-en-go/exercises

Tu primer programa

Todo programa de Go empieza en la función main del paquete main:

{{code "examples/hello/main.go"}}

Tu turno

Abre hello.go y escribe tú la función entera, con su cuerpo entre llaves como en main. Devuelve el saludo con return; el operador + une dos textos. 

func Greeting(name string) string

Ejecuta go test antes de escribir nada: falla con undefined: Greeting, porque el test llama a una función que todavía no existe. Es normal; es tu punto de partida.
