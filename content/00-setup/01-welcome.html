Este curso es un paseo por Go pensado para quien recién empieza. Cada lección explica un concepto, muestra un ejemplo y, cuando corresponde, propone un ejercicio que se resuelve en tu propia computadora.

Cómo funciona

  1. Leé la lección en esta web.
  2. Abrí la carpeta del ejercicio en tu editor y completá el código.
  3. Corré go test. Cuando todos los tests pasan, el ejercicio está resuelto.
  4. Marcá la lección como completada. Tu progreso se guarda en este navegador.

Instalar Go

Descargá Go desde go.dev/dl y verificá la instalación en una terminal: 

go version

Descargar los ejercicios

git clone https://github.com/OWNER/paseo-en-go.git
cd paseo-en-go/exercises
