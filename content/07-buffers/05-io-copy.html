Quieres copiar un archivo en otro, o guardar en un archivo lo que llega por la red. Si lo lees todo en memoria y luego lo escribes, un archivo de 4 GB necesita 4 GB de memoria. Lo que quieres es pasar los datos por trozos: leer un poco, escribirlo y repetir.

El concepto

io.Copy(dst, src) hace justo eso. Lee de un io.Reader y escribe en un io.Writer a través de un buffer pequeño que reutiliza, hasta que Read devuelve io.EOF.

Devuelve cuántos bytes ha copiado y el primer error que encuentra. io.EOF no cuenta como error: es el final esperado. Funciona con cualquier pareja: archivos, conexiones de red, strings.Reader o bytes.Buffer.

En la memoria

Animación: un buffer de 4 bytes entre src y dst. Cada vuelta, Read llena el buffer con el siguiente trozo de "Hola, Gopher" y Write lo lleva al destino. Tras tres vueltas, el siguiente Read devuelve io.EOF y la copia termina.

Un error a propósito

package main

import (
	"io"
	"os"
	"strings"
)

func main() {
	src := strings.NewReader("hola\n")
	io.Copy(src, os.Stdout) // los argumentos, al revés
}
./prog.go:11:10: cannot use src (variable of type *strings.Reader) as io.Writer value in argument to io.Copy: *strings.Reader does not implement io.Writer (missing method Write)

Cómo leer el error

./prog.go:11:10: cannot use src (variable of type *strings.Reader) as io.Writer value in argument to io.Copy: *strings.Reader does not implement io.Writer (missing method Write)

El primer argumento de io.Copy es el destino y tiene que ser un io.Writer. src sabe leer, pero le falta el método Write (missing method Write). El orden es el de una asignación, dst = src: primero adónde va y luego de dónde viene.

El error típico

Leerlo todo en memoria para copiarlo:

data, err := io.ReadAll(src) // todo el archivo en memoria
if err != nil {
	return err
}
_, err = dst.Write(data)

Con un archivo pequeño no notas nada; con uno de varios GB, tu programa se queda sin memoria. io.Copy(dst, src) hace lo mismo con un buffer de unos pocos KB.
