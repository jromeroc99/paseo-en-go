Quieres leer un texto línea a línea: un registro, una lista, lo que escribe alguien en el teclado. Con Read recibes trozos de bytes del tamaño que toque, y una línea puede quedar partida entre dos trozos. Tendrías que juntar tú los trozos y buscar cada salto de línea.

El concepto

bufio.Scanner lo hace por ti. Envuelve un io.Reader, llena su buffer con pocas llamadas a Read y lo corta en tokens, trozos de texto: por defecto, líneas.

Cada Scan avanza al siguiente token y devuelve false cuando no quedan. Text te da el token, sin el salto de línea. Al terminar el bucle, Err te dice si ha parado por un error o porque se ha acabado el texto.

En la memoria

Animación: el primer Scan llena el buffer del Scanner con todo el texto en un solo Read. Después corta en cada salto de línea: Text() da "uno", "dos" y "tres", y el programa los imprime. Cuando no quedan líneas, Scan devuelve false.

Un error a propósito

El buffer del Scanner tiene un límite: un token puede ocupar como mucho 64 KB. Prueba con una sola línea de 70 000 bytes: 

package main

import (
	"bufio"
	"fmt"
	"strings"
)
func main() {
	long := strings.Repeat("a", 70000) // una sola línea de 70 000 bytes
	scanner := bufio.NewScanner(strings.NewReader(long))
	for scanner.Scan() {
		fmt.Println(len(scanner.Text()))
	}
	fmt.Println("error:", scanner.Err())
}
error: bufio.Scanner: token too long

Cómo leer el error

error: bufio.Scanner: token too long

«Token demasiado largo». La línea no cabe en el buffer, así que el primer Scan se rinde y devuelve false: no se imprime ningún número. Si no miraras Err, el programa terminaría en silencio, como si el texto estuviera vacío. Si esperas líneas tan largas, dale un buffer mayor con scanner.Buffer.

El error típico

Olvidar que Text quita el salto de línea:

for scanner.Scan() {
	fmt.Print(scanner.Text()) // "unodostres": los saltos se han perdido
}

Si quieres conservar las líneas, añade tú el salto: fmt.Println o scanner.Text() + "\n".
