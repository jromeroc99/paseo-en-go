Quieres construir un texto poco a poco: una cabecera y luego una línea por cada dato. Con s += parte, cada suma crea un string nuevo y copia todo lo anterior, porque un string no se puede cambiar. Con mil partes, copias el principio del texto mil veces. Necesitas un sitio donde ir añadiendo bytes sin copiarlo todo cada vez.

El concepto

bytes.Buffer es ese sitio: un slice de bytes que crece cuando escribes. Write y WriteString añaden al final; Read lee desde el principio y avanza. Len() dice cuántos bytes quedan sin leer y String() los devuelve como texto.

Su valor cero ya sirve: declara var buf bytes.Buffer y escribe. Como *bytes.Buffer tiene un método Write, es un io.Writer: puedes pasárselo a fmt.Fprintf.

En la memoria

Animación: el buffer empieza vacío. WriteString("uno ") y Write([]byte("dos")) añaden bytes al final, y Len() pasa a 7. Read copia los 4 primeros en b y avanza: quedan 3 sin leer, y String() es "dos".

El ejemplo

Fíjate en que Read no borra el texto: avanza. Después de leer 4 bytes, Len() baja de 7 a 3 y String() solo devuelve lo que queda sin leer.

Un error a propósito

package main

import (
	"bytes"
	"fmt"
)

func main() {
	var buf bytes.Buffer
	fmt.Fprintf(buf, "hola %d", 7) // el buffer, tal cual
	fmt.Println(buf.String())
}
./prog.go:10:14: cannot use buf (variable of struct type bytes.Buffer) as io.Writer value in argument to fmt.Fprintf: bytes.Buffer does not implement io.Writer (method Write has pointer receiver)

Cómo leer el error

./prog.go:10:14: cannot use buf (variable of struct type bytes.Buffer) as io.Writer value in argument to fmt.Fprintf: bytes.Buffer does not implement io.Writer (method Write has pointer receiver)

«No puedo usar buf como io.Writer». El final te da el motivo: Write tiene un pointer receiver, es decir, está declarado sobre *bytes.Buffer. Solo el puntero es un io.Writer. Pasa su dirección: fmt.Fprintf(&buf, "hola %d", 7).

El error típico

Pasar el buffer a una función por valor:

func header(buf bytes.Buffer) { // recibe una copia
	buf.WriteString("Informe\n")
}

Compila, porque dentro de la función buf es una variable y Go toma su dirección por ti. Pero escribe en la copia, y tu buffer se queda como estaba. Pasa siempre un *bytes.Buffer, como en el ejercicio.
