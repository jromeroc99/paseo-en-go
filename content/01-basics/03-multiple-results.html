Imagina que divides 7 entre 2. Te interesa el cociente, 3, pero también el resto, 1. En muchos lenguajes tendrías que escribir dos funciones o meter los dos números en una estructura. En Go una función puede devolver los dos a la vez.

El concepto

Para devolver varios valores, escribe sus tipos entre paréntesis y sepáralos con comas en el return. Quien llama a la función recibe cada valor en su propia variable: 

a, b := swap("hola", "mundo")

Resultados con nombre

Los resultados también pueden tener nombre. Entonces funcionan como variables declaradas al principio de la función, y un return sin nada detrás devuelve sus valores actuales. A eso se le llama un return desnudo.

Un error a propósito

Si la función devuelve dos valores, necesitas dos variables para recibirlos:

package main

import "fmt"

func swap(x, y string) (string, string) {
	return y, x
}

func main() {
	a := swap("hola", "mundo")
	fmt.Println(a)
}
./prog.go:10:7: assignment mismatch: 1 variable but swap returns 2 values

Cómo leer el error

./prog.go:10:7: assignment mismatch: 1 variable but swap returns 2 values

El mensaje es muy literal: en la línea 10 hay una variable a la izquierda, pero swap devuelve dos valores. Añade la segunda variable y compila.

El error típico

El return desnudo es cómodo, pero esconde qué se devuelve. En una función de tres líneas se ve de un vistazo; en una de cincuenta tienes que buscar dónde se asignó cada resultado. Úsalo solo en funciones cortas y, ante la duda, escribe los valores: return x, y.
