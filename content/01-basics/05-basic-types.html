No es lo mismo guardar una edad que un precio o un nombre. La edad es un número entero, el precio lleva decimales y el nombre es texto. Cada valor de Go tiene un tipo, y el tipo decide qué operaciones puedes hacer con él.

El concepto

Estos son los tipos básicos que vas a usar casi siempre:

  • bool: verdadero o falso, true o false.
  • string: texto, entre comillas dobles.
  • int: números enteros. También existen int8, int16, int32 e int64, con un tamaño fijo, y sus versiones sin signo uint, uint8… que no admiten negativos.
  • byte: otro nombre para uint8. Se usa para datos en bruto.
  • rune: otro nombre para int32. Representa un carácter Unicode y se escribe entre comillas simples: 'G'.
  • float64: números con decimales.

Regla práctica

Go también tiene números complejos, complex128, pero no los necesitarás en este curso.

Regla práctica: para enteros, usa int salvo que tengas una razón concreta para usar otro tamaño.

Un número en 8 bits

Animación: un int8 guarda 127 en 8 bits, 0111 1111; el primer bit es el signo. b++ suma 1 y el acarreo llega hasta el bit de signo: 1000 0000. Go lo lee como -128. El número da la vuelta sin avisar.

Un error a propósito

Sumar un int y un float64 parece inofensivo:

package main

import "fmt"

func main() {
	apples := 3
	price := 0.5
	fmt.Println(apples + price)
}
./prog.go:8:14: invalid operation: apples + price (mismatched types int and float64)

Cómo leer el error

./prog.go:8:14: invalid operation: apples + price (mismatched types int and float64)

Mismatched types significa «tipos que no coinciden». Go no mezcla tipos numéricos por su cuenta: tienes que convertir uno de ellos. Lo verás en la lección de conversiones.

El error típico

La división entre enteros da un entero: 7 / 2 vale 3, no 3.5. Los decimales se descartan. Si necesitas el resultado exacto, trabaja con float64: 7.0 / 2 vale 3.5.
