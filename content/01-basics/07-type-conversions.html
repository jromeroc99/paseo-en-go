En la lección anterior viste que Go no deja sumar un int y un float64. Pero a veces necesitas hacerlo: tienes los lados de un triángulo como enteros y math.Sqrt solo acepta float64. Tienes que decirle a Go, de forma explícita, que quieres cambiar el tipo.

El concepto

La expresión T(v) convierte el valor v al tipo T: 

i := 3
f := float64(i) // 3.0
n := int(f)     // 3

Go nunca convierte por su cuenta, ni siquiera entre tipos numéricos. Al principio parece incómodo, pero evita errores que en otros lenguajes pasan desapercibidos.

Inferencia de tipos

Lo que sí hace Go es deducir el tipo cuando declaras con := o con var sin tipo. A eso se le llama type inference (inferencia de tipos): la variable toma el tipo del valor de la derecha. 42 da un int y 3.142, un float64.

Un error a propósito

Guardar un float64 en una variable int sin convertir:

package main

import "fmt"

func main() {
	var total int
	price := 9.75
	total = price
	fmt.Println(total)
}
./prog.go:8:10: cannot use price (variable of type float64) as int value in assignment

Cómo leer el error

./prog.go:8:10: cannot use price (variable of type float64) as int value in assignment

El compilador te dice qué tiene (price, de tipo float64), qué esperaba (un int) y dónde (en una asignación, línea 8). La solución es convertir: total = int(price).

El error típico

Pensar que int(f) redondea. No lo hace: trunca, es decir, descarta los decimales. Si price vale 9.75, int(price) vale 9, no 10. Si quieres redondear, usa math.Round antes de convertir.
