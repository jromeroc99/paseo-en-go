Hay valores que nunca cambian mientras el programa se ejecuta: el número pi, los días de la semana, el nombre de tu aplicación. Si los guardas en una variable, cualquier parte del código podría modificarlos por error. Para eso existen las constantes.

El concepto

Una constante se declara como una variable, pero con const. Puede ser un texto, un carácter, un booleano o un número, y su valor tiene que conocerse al compilar. Por eso no puedes usar := con ellas. 

const Pi = 3.14

Las constantes numéricas tienen una particularidad: si no les pones tipo, son valores de alta precisión untyped (sin tipo). Toman el tipo que necesita el sitio donde las usas. La misma constante puede ir a una función que espera un int y a otra que espera un float64.

Un error a propósito

¿Y si pasas Big a una función que espera un int?

package main

import "fmt"

const Big = 1 << 100

func needInt(x int) int { return x*10 + 1 }

func main() {
	fmt.Println(needInt(Big))
}
./prog.go:10:22: cannot use Big (untyped int constant 1267650600228229401496703205376) as int value in argument to needInt (overflows)

Lee el final del mensaje: overflows, «se desborda». El valor de la constante no cabe en un int, y Go te avisa al compilar en vez de dejar que el número se corrompa en silencio.

El error típico

Intentar cambiar el valor de una constante:

package main

import "fmt"

const Pi = 3.14

func main() {
	Pi = 3.1416
	fmt.Println(Pi)
}
./prog.go:8:2: cannot assign to Pi (neither addressable nor a map index expression)

El mensaje es algo técnico, pero la idea es simple: a Pi no se le puede asignar nada. Si el valor tiene que cambiar, no es una constante: usa una variable.
