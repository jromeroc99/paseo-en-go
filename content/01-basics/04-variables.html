Un programa necesita recordar cosas mientras se ejecuta: un nombre, una puntuación, si el usuario ya ha iniciado sesión. Para eso están las variables, cajas con nombre donde guardas un valor.

El concepto

La forma completa usa var, el nombre y el tipo: 

var c, python, java bool

Con valor inicial

Puedes declarar variables fuera de cualquier función, a nivel de paquete, o dentro de una función. Si les das un valor inicial, el tipo es opcional: Go lo deduce del valor. 

var i, j int = 1, 2
var language = "Go"

La declaración corta

Dentro de una función existe un atajo, la short variable declaration (declaración corta): := declara la variable y le da su valor en un solo paso, sin escribir var ni el tipo.

En la memoria

Animación: var count int reserva una caja en la memoria, con su dirección, que empieza valiendo 0. count = 42 escribe en esa misma caja. other := count crea otra caja y copia el 42; cambiar other no toca count.

Un error a propósito

:= solo funciona dentro de una función. Fíjate en qué pasa fuera:

package main

import "fmt"

name := "Gopher"

func main() {
	fmt.Println(name)
}
./prog.go:5:1: syntax error: non-declaration statement outside function body

Cómo leer el error

./prog.go:5:1: syntax error: non-declaration statement outside function body

Fuera de las funciones, cada línea debe empezar por una palabra de declaración: var, const, func, type o import. La línea 5 no empieza por ninguna, así que el compilador ni siquiera la entiende. Escribe var name = "Gopher".

El error típico

Declarar una variable dentro de una función y no usarla nunca:

package main

func main() {
	count := 10
}
./prog.go:4:2: declared and not used: count

Cómo arreglarlo

./prog.go:4:2: declared and not used: count

Igual que con los imports, Go no deja pasar lo que sobra. Si una variable no se usa, casi siempre es un despiste: o te has olvidado de usarla o ya no la necesitas. Bórrala o úsala.

Escribe en seconds.go una función que convierte horas, minutos y segundos en segundos. Guarda cada parte en una variable con := antes de sumarlas: una hora son 3600 segundos y un minuto, 60.
