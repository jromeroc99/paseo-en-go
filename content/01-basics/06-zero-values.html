¿Qué vale una variable que declaras sin darle valor? En algunos lenguajes, cualquier cosa: lo que hubiera en esa zona de memoria, o un valor especial como undefined que hace fallar el programa más adelante. En Go la respuesta es siempre la misma y es predecible.

El concepto

Toda variable declarada sin valor inicial recibe el zero value (valor cero) de su tipo:

  • 0 para los números.
  • false para bool.
  • "", el texto vacío, para string.

Así, una variable siempre está lista para usarse. Un contador empieza en cero, una bandera empieza desactivada y un texto empieza vacío, sin que tengas que escribirlo.

Esto te da una regla sencilla para elegir cómo declarar. Si ya tienes el valor, usa :=: name := "Gopher". Si quieres empezar desde cero y rellenar la variable después, usa var sin valor: var total int. Quien lea tu código entenderá que total empieza en cero a propósito.

El error típico

Escribir código defensivo para un valor que no puede existir. Esto sobra: 

var total int
total = 0 // innecesario: total ya vale 0

Aprovecha el valor cero. Muchos tipos de la biblioteca estándar están diseñados para que su valor cero ya funcione, y verás que tus propios tipos también pueden hacerlo.
